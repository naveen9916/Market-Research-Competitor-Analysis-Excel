# Market Research and Competitor Analysis Using Microsoft Excel

## Project Overview
This project focuses on analyzing company performance, product pricing, sales revenue, customer ratings, marketing expenses, and market trends using Microsoft Excel.

The objective is to transform raw data into meaningful business insights using Excel formulas, data cleaning, PivotTables, charts, and interactive dashboards.

## Objectives
- Compare the performance of different companies.
- Analyze product prices, sales revenue, and customer ratings.
- Evaluate marketing expenses and business performance.
- Identify regional sales patterns and monthly trends.
- Create interactive dashboards for business reporting.
- Develop practical data analysis and research skills.

## Tools and Technologies
- Microsoft Excel
- Excel Formulas and Functions
- PivotTables and PivotCharts
- Conditional Formatting
- Data Validation
- Excel Charts and Dashboards
- Data Cleaning and Analysis

## Dataset Details
- **Total Records:** 1,800
- **Companies:** 6
- **Products:** 25
- **Categories:** 5
- **Regions:** 5
- **Date Range:** January 2024 – December 2025

**Note:** The dataset contains simulated data created for educational and portfolio purposes. Company names, sales, prices, customer ratings, and marketing expenses are fictional and do not represent verified real-world market information.

## Key Features
- Company performance comparison
- Sales and revenue analysis
- Product pricing and customer rating comparison
- Marketing expense analysis
- Regional performance analysis
- Monthly market trend analysis
- Data cleaning and formatting
- PivotTables and PivotCharts
- Interactive Excel dashboard with slicers
- KPI summaries and visual reports

## Dashboard Components
1. **Market Overview Dashboard** – Summarizes key performance indicators, sales, revenue, and overall market performance.
2. **Competitor Analysis Dashboard** – Compares companies based on product pricing, customer ratings, sales, and marketing expenses.
3. **Regional and Trend Analysis Dashboard** – Highlights regional performance and monthly market trends.

## Project Workflow
1. Import the dataset into Microsoft Excel.
2. Clean and format the data.
3. Apply Excel formulas and functions for analysis.
4. Create PivotTables to summarize business performance.
5. Develop charts and visualizations using PivotCharts.
6. Build an interactive dashboard using slicers and KPI summaries.
7. Analyze the results and identify business trends.
8. Document the findings and save the completed workbook.
